研究ノート
1. Infoに権限の文言を追加
Privacy - Hands Tracking Usage descriptionをターゲット設定からInfoタブに行って新しいキーを追加した。でも本来はここ（Xcode UI）で追加するとキーの形式が正しく変換されて追加されるはずなのに、Infoファイルでソースコードを確認したらキーの形式が間違っていることがわかった。ソースコードを修正してから実行すると、権限ポップアップがちゃんと表示された。
2. ハンドトラッキングを動作させる
その後、Immersive Spaceを開かないとハンドトラッキングが動作しないため、Content ViewからImmersive Spaceを開くように修正した。
3. ローカル座標をワールド座標に変換
Immersive Spaceは開くものの、座標が0になってしまう（HandTrackingManagerファイルを修正）。anchorFromJointTransformはアンカー基準のローカル座標なので、0に近くなり得ることを確認 → ワールド座標に変換することに。anchorFromJointTransformをoriginFromAnchorTransformに変更。つまり、行列の掛け算で座標系をローカル → ワールドに変換した。
4. Immersive SpaceとUI表示の分離
ImmersiveViewでoverlayとしてテキストを表示しようとしたが、Immersive Spaceは全体が3D空間なので、2D overlayがうまくレンダリングされなかったようだった → Immersive ViewはImmersive Spaceを開く役割だけにして、UI表示はContent Viewのウィンドウで担当するように分離した。
Immersive Spaceだけ開いて、manager.start()はImmersive Viewの.taskで呼び出した → Immersive ViewのmanagerとContent Viewのmanagerが別々のインスタンスだったため、Immersive Viewで受け取ったデータがContent Viewの画面に反映されなかった → ContentViewが直接所有するmanagerでstart()を呼び出すので、データが入ってくると同じインスタンスのleftWristPosition/rightWristPositionが更新され、SwiftUIが画面を更新するようにした。openImmersiveSpaceを先に呼び出す理由は、Immersive Spaceが開かないとARKitのハンドトラッキングが実際に動作しないため。
これでXcodeのログにもちゃんと表示され、AVPの画面上にもちゃんと表示されるようになった。
